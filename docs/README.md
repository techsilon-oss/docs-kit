# docs-kit docs

Where to find things. Each subject folder has a `README.md` that maps it.

- [guides](guides/README.md): how-tos to adopt, reorganise, print, upgrade and remove docs-kit.
- [reference](reference/README.md): every command, option, finding and exit code.

At the docs root:

- [DESIGN.md](DESIGN.md): the layout rule, the parts, the hazards, the rollout, and why each part works the way it does.
- [FAQ.md](FAQ.md): short answers that link to the guides.
- [UPGRADING.md](UPGRADING.md): renames and breaking changes, one section per release.

This folder follows the docs-kit layout, and `npm test` checks it.
